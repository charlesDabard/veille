DÉFINITION

C'est quoi, une skill ?

Une skill, c'est un fichier markdown que l'agent lit, avec une description qui lui dit QUAND se réveiller et un corps qui lui dit QUOI faire.
un fichierun déclencheurune procédure
ACTE 2 · L'IDÉE

La description EST le déclencheur.

skill/SKILL.md
---
name: veille
description: Veille multi-sources (YouTube, Google News, Hacker News, Reddit,
  GitHub, RSS, X par URLs collées, web) qui construit une base de connaissance
  locale. Se déclenche sur « /veille <sujet> », « fais une veille sur … »
  ou « veille sur … ». Demande toujours quelles sources activer.
  Mode lecture, « cherche dans ma veille <question> ». Mode maintenance,
  « lint ma veille ». Ne se déclenche jamais de façon proactive.
---

L'agent relit cette description à chaque message : c'est elle qu'on optimise.

DÉFINITION

C'est quoi, la KB ?

Un dossier de markdown et de JSON versionné git : un sous-dossier par sujet, les bruts d'un côté, les notes distillées de l'autre.
~/veille-kb/
agent-loops/   claude-code-tips/   ia-agents-perso/   llm-modeles/   […]

claude-code-tips/
├── _bruts/        ← les transcripts (JSON)
├── notes/         ← les notes distillées (markdown)
├── _index.md      ← les sources déjà ingérées
└── SYNTHESIS.md   ← la synthèse vivante du sujet

ACTE 4 · DÉMO

Question, réponse, sources.

claude
> cherche dans ma veille : c'est quoi cette règle des 40 % de contexte
  dont parlent les tutos Claude Code ?

D'après la base (sujet claude-code-tips) :
La règle vient de la vidéo « Claude Code : le guide complet pour les
non-devs (2026) » de Shubham SHARMA (2026-07-10) : la fenêtre de contexte
est la mémoire de travail de Claude Code ; plus elle se remplit, moins il
est efficace, donc surveiller qu'elle ne dépasse pas ~40 %.
Nuance notée à la distillation : c'est une heuristique du créateur, pas
un seuil officiel Anthropic (classée « claims douteux » dans la note).

Sources :
· notes/_pW-kUBo7AU.md (claude-code-tips)
· https://www.youtube.com/watch?v=_pW-kUBo7AU

La réponse vient de la note de NOTRE vidéo : pas du web.

ACTE 5 · À VOUS

Faites la vôtre en 4 étapes.

  • 1.La description : quand se déclencher, quand surtout pas.
  • 2.La politique dans le corps : étapes, questions, sorties.
  • 3.Les mécanismes en scripts minces (stdlib, pas de deps).

Et le mot magique se change en une ligne : la description du skill.
